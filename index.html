核心功能

四大作业系统，一条流水线

前一步的产物就是后一步的输入，全部数据落在项目库中，团队同源不抄错数。

01

项目管理

一键建库（cy_单位_年度）并生成读取 / 调整 / 注释 / 报告四套底稿；按账号授权隔离项目数据。

02

读取系统

递归扫描外部报表，并行解析 BS / IS / CF / CE，勾稽校验后一键写入未审报表。

03

调整系统

合并结构、调整分录入库；TB / FS / conTB 一键查询，支持分部口径与批量导出 xlsx / PDF。

04

注释与报告

注释目录驱动建表、GUID 增量上传、三种勾稽表；一键生成 Excel 注释副本与 Word 审计报告。

技术亮点

为「现场可用」做的工程决策

纯桌面架构

客户端不直连数据库，所有读写经 Api 中继并按账号签发专属凭据——机器上无需装任何驱动。

一项目一库

MySQL 按项目物理隔离（cy_单位_年度），权限天然收敛到库级别，数据安全不靠自觉。

并行解析引擎

外部报表 NPOI 多线程解析 + 失败自动 COM 兜底，百份底稿秒级完成。

GUID 增量同步

注释与调整分录按行标识快照比对，只传差异行，断点续写不重复。

WPS 兼容宿主

独立宿主进程 + COM 适配，在 WPS 12.x 上还原 100% 功能面，秒级冷启动。

三层权限门

界面灰置 / 入口宏守门 / 服务端硬校验同源判定，权限规则改一处全端生效。
