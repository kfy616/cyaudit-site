产品概览

CYAudit 是面向中小会计师事务所与独立审计师的桌面端审计作业系统。它由 Excel/WPS 加载项、云端 Api 服务与按项目隔离的 MySQL 项目库组成：客户端负责读表、填表、算表，所有跨进程取数与写库经 Api 中继并按账号授权，本机无需安装数据库驱动。 项目管理、合并结构、未审数、调整分录、注释底稿与审计报告全部数据化，团队在同一项目库上协作，数字有源可溯。

功能总览（42 个功能按钮）

① 项目管理

  • 一键新建项目：建库（cy_单位_年度）+ 生成读取 / 调整 / 注释 / 报告四套底稿工作簿
  • 项目维护与状态管理；用户管理（仅管理员）；按项目角色授权成员

② 读取系统（5 按钮）

  • 匹配报表项目：模板报表项目 ↔ 科目信息自动匹配，未匹配项标注「待确认」
  • 获取文档路径 + 批量提取数据：递归扫描外部报表，NPOI 并行解析 BS / IS / CF / CE
  • 勾稽校验：25 个勾稽科目按层级递归汇总，差异自动定位
  • 上传数据：按 截止日 + 单位 + 科目 REPLACE 写入未审报表

③ 调整系统（15 按钮）

  • 上传单位清单 / 分部清单：合并范围唯一数据源，覆盖式入库
  • 上传前期审定数 / 未审数 / 调整分录：借贷勾稽校验 + GUID 增量同步
  • 查询 TB / FS / FS1 / conTB：支持「审计期初数」双口径与分部合并例程
  • 批量导出：单位 × 工作表 → xlsx / PDF，合并或分拆，五步向导

④ 注释系统（17 按钮）

  • 注释目录驱动建表 / 改表：zs{表名} 幂等增量，不丢已录数据
  • 上传当前 / 全部注释：四态计数（新增/更新/删除/未变动）可查漏
  • 三种勾稽表：报表数 vs 注释数、合计 vs 明细、抵销数 vs 注释数
  • 查询当前 / 多表注释、导入上期注释（期初自动衔接上年期末）

⑤ 报告生成系统（2 按钮）

  • 生成 Excel 注释：按单位复制母版并填值，合并单位自动切换合并模板
  • 生成审计报告（Word）：封面 / 正文 / 目录 / 报表 / 附注五文档自动合并，占位符替换，模板格式零改动

适用场景与目标用户

年报审计项目组

3–10 人小团队共用项目库，谁改了什么操作日志全留痕。

合并报表业务

多层合并结构 + 抵销分录 + 合并 TB / 合并注释，自动展开层级。

连续年度审计

跨年项目一键导入上期注释，期初取数口径自动切换。

Excel / WPS 双宿主

WPS 环境通过独立宿主进程跑同一套功能，现场零门槛。

目标用户：中小会计师事务所 · 独立审计师 · 财务尽调团队 · 对底稿自动化有兴趣的 CPA。

技术亮点

  • 纯桌面架构：客户端不直连数据库，Api 中继 + 按账号签发专属 MySQL 凭据，物理级数据隔离
  • 一项目一库：权限天然收敛到库级别；归档 / 停用项目自动回收访问权
  • 并行解析引擎：外部报表多线程解析，失败自动 COM 兜底重试，单文件只打开一次
  • GUID 增量同步：写库类操作快照比对只传差异，断点续写不重复、不丢行
  • 三层权限门：界面亮灰 / 入口宏守门 / 服务端硬校验同源判定（职级 + 项目角色双层）
  • WPS 兼容宿主：托盘常驻进程 + jsaddons 选项卡，COM 适配层还原完整功能面

技术栈：C# / .NET 8–9 · Excel-DNA · ASP.NET Core 最小 API · MySQL · NPOI / ClosedXML / OpenXML SDK。
