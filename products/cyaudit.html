产品概览

CYAudit 是面向中小会计师事务所与独立审计师的桌面端审计作业系统。它由 Excel/WPS 加载项、云端 Api 服务与按项目隔离的 MySQL 项目库组成：客户端负责读表、填表、算表，所有跨进程取数与写库经 Api 中继并按账号授权，本机无需安装数据库驱动。 项目管理、合并结构、未审数、调整分录、注释底稿与审计报告全部数据化，团队在同一项目库上协作，数字有源可溯。
